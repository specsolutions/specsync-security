# Security policy

## Reporting a vulnerability

Please report security issues in SpecSync by e-mail to **specsync@specsolutions.eu**. Do not open a public issue or pull request for a security issue.

We acknowledge a report within 2 business days and keep you informed until the issue is resolved. The full reporting instructions, our security advisories and how we handle vulnerabilities are on the [Security page](https://docs.specsolutions.eu/specsync/contact/security) of the SpecSync documentation.

## This repository

This repository only publishes security information about SpecSync (the VEX document and the release checksums). It does not contain the SpecSync source code.
